# 봉인 시험지 설계 — 2판 (보이저 세션; 1판 2026-10-12, 2판 2026-10-13)

**상태: 2판 — 사용자 승인(2026-10-13): 9절의 변경 열 가지와 개발 씨앗 사례(9절 10번) 그대로.** 1판(2026-10-12)에 두 형제 세션의 의견(8절, 각자 저장소의 `EXAM_REPLY.md`)을 반영해 1~5절을 고쳤다. 고친 곳에는 "(2판)"을 붙였다. 고정한 뒤에 바꾸는 것은 다음 판부터만 한다.
이미 승인된 것(2026-10-12, `STAGE1.md` 끝 절과 `RULES.md` 5번)은 이 문서의 전제다.
- 세 모델이 같은 날 함께 연다.
- 판을 거듭한다.
- 문항은 여는 날 사용자의 씨앗으로 만든다.
- 완성은 다음 판에서 한 번 더 확인해야 적는다.
- 판 사이는 최소 2주다.
- 기준선은 판마다 같은 문항으로 돌린다.

## 0. 이해 충돌 막기
보이저 세션은 시험지를 만들면서 보이저에게도 시험을 보게 한다. 그래서 다음을 지킨다.
- **문항은 여는 날 전까지 존재하지 않는다**(사용자 씨앗). 생성 코드·채점 코드·통과선·기준선 실행기는 **미리 공개하고 고정**해서, 형제 세션이 읽고 따질 수 있게 한다.
- **시험 세상은 세 모델 누구의 개발 세상과도 겉모습이 다르다.** 보이저 고유의 형식(글자 그림 등)을 쓰지 않는다. 형식은 RULES 1의 "문장 + 장면 기록(칸)"만 쓴다.
- 형제 의견과 사용자 승인을 거친 뒤에 고정한다. 고정한 뒤에 바꾸는 것은 다음 판부터만 한다.
- **(2판) 개발 씨앗 사례**: 공개된 생성 코드로 "정한 개발 씨앗"(사용자 씨앗이 아님)의 사례를 만들어 각 세션이 변환기를 시험할 수 있다. 그 사례로 몸을 학습시키지는 않는다(사용자 승인 2026-10-13). 문항이 아니라 생성 규칙만 쓰는 것이라 "시험지는 학습 재료가 아니다"에 어긋나지 않는다.

## 1. 한 판의 모양 — "시험 생애"
- **시험 = 새 세상에서 처음부터 사는 생애 하나.** 각 모델은 지금 자기 개발 세상에서 생애를 돌리는 것과 같은 방식으로, 시험 세상에서 생애를 산다.
  - 회차마다 문장 + 장면 기록을 듣는다(노출 단계). 회차가 끝날 때마다, 그리고 생애 끝에 시험 문항에 답한다.
- **무엇을 재나**: 각 모델의 학습 장치와 부품이 처음 보는 공용 세상에서도 1단계 능력을 만들어 내는가. 개발 세상에서 배운 낱말을 옮겨 오지는 않는다(낱말의 뜻을 손으로 이어 주면 그것이 변환기의 몫이 된다 — RULES 4).
- **"시험지는 학습 재료가 아니다"는 이렇게 지킨다**: 시험 세상은 여는 날 그 생애 안에서만 쓰고 은퇴시킨다. 개발에 쓰지 않는다.
- **시드**: 모델마다 30생애씩 두 조건(부품 포함 = 판정 대상, 몸 혼자 = 함께 보고 — STAGE1 공통 규칙)이라 판마다 모델당 60생애. 사용자 씨앗 → 판의 으뜸 씨앗 → 생애마다 다른 세상 사례(같은 규칙, 다른 방·물건·낱말 배치)와 다른 노출 순서. 미결이면 100생애(2단계 규칙).
- **크기(RULES 8 범위 안)**: 격자 5×5, 인물 동시 3명 이하, 한 문장 한 사건, 회차 16.
  - **(2판) 노출은 과목별 최소 노출 수로 정한다.** 세 세션이 각자 "과목 하나를 배우는 데 든 노출 수"를 적으면 그 가운데 값을 과목의 최소 노출 수로 쓴다(뉴호라이즌스: 이동 규칙 본 사건 900~1,300, 이름 이야기 약 80). 숫자가 모일 때까지의 초안은 생애 하나에 약 1,500문장이다.
  - 과목별 노출 곡선(시작, 90% 도달까지의 노출 수, 끝)을 보고한다.
  - 계산 시간(정보): 파이오니어 기본 몸은 생애 하나 20~40분(방법 층은 약 2시간), 뉴호라이즌스는 수 분.
- **(2판) v2부터**: 시험 세상에 "규칙이 바뀌는 회차" 하나를 넣어 기준 11(세상 변화 따라잡기)을 같은 생애에서 잰다. v1에서는 보고하지 않는다.

## 2. 시험 세상의 내용 (기준 0~9를 모두 담음)
| 담는 것 | 장면 기록의 칸 | 쓰는 기준 |
|---|---|---|
| 인물·물건·장소, 이동 | 누가, 무엇을, 어디(칸 좌표, 장소 이름), 언제(회차 안의 순간 번호) | 0, 1, 2, 7, 8 |
| 물건 여러 개(1~10), 넣기·빼기 | 물건마다의 자리(개수는 적지 않음; 상자 안은 가림으로) | 3, 4 |
| 중력·받침, 단단함, 부딪힘으로 움직임이 전해짐, 가려진 동안의 대상 영속성 | 순간마다 물건의 자리, 가림(받침은 적지 않음 — 몸이 자리에서 배움) | 6 |
| 공간 관계(위·아래·안·옆) | 두 물건의 자리(관계 이름은 적지 않음) | 9 |
| 두 언어 — 같은 사건을 한국어식(조사 + 끝에 동사)과 영어식(주어-동사-목적어 + 전치사)으로 | 언어 표시 없음(2판) | 5 |
| 이야기(2~4순간, 2배 긴 이야기 따로) | 순간 번호 | 7, 8 |

**(2판) 장면 기록의 형식**: **물건마다 한 줄**(물건 id + 그 물건의 칸들). 순서 없는 몸도 "어느 물건이 어디"를 섞지 않게 하고, 변환기가 몰래 묶어 주는 몫이 생기지 않게 한다. 물건의 특징 벡터는 **물건 id로 시드를 정한 난수**다(규칙만 공개 — 두 언어의 낱말이 같은 물건을 가리킴). 받침·안팎·개수 같은 관계·요약 칸은 주지 않는다(정답이 입력에 들어가는 것을 막고, 관계는 몸이 배운다). 언어 표시도 주지 않는다.

**낱말(사용자 결정 2026-10-12 — 6절)**
- **닫힌 낱말은 실제 말을 쓴다**:
  - 수 낱말 1~10(두 언어)
  - 공간 말(위·아래·안·옆 / on·under·in·beside)
  - 의문사
  - 조사(가·를·에·에서 등)와 전치사

  **목록: `exam_spec/closed_words.json`**(closed-v1). 사용자 결정(2026-10-12)에 따라 보이저 세션이 사전 표제어(표준국어대사전, 영어 사전)에서 모았다. 뜻풀이는 옮기지 않고 낱말만 쓴다.
  담은 것: 수 1~10(한국어는 이름 뒤에 놓는 수사 "공 셋"), 공간 말 넷, 의문사(몇 개 포함), 조사(받침에 따라 이/가·을/를·으로/로), 영어 기능어(to·from·there is/are), 있다.
  **(2판)** 조사 이형태 짝(이/가, 을/를, 으로/로)은 모두 요소 목록에 넣고 기준 0의 요소 기억 점검에 포함한다.
- **열린 낱말(인물·물건·장소·동사)은 판마다 새로 만드는 가짜 낱말**로 한다(생성 규칙으로, 두 언어 각각).
  - 판마다 겉모습이 새로워지고, 어느 모델도 미리 알 수 없다.
  - 아이 언어 연구의 "가짜 낱말 시험"과 같은 방식이다.
  - 대안: 공개된 기초 어휘 목록(이용 조건 확인 뒤)에서 판마다 뽑기.

## 3. 기준별 문항 (STAGE1 2판의 통과선 그대로)
답 형식은 셋뿐이다: **빈칸 하나 / 보기 고르기 / 장면 칸**. 모든 몸이 출력 확률만으로 답할 수 있다. 어순이 있어야만 풀리는 문항에는 표시를 달고 따로 보고한다(RULES 6).

**(2판) 후보·오답·표시**
- **문항마다 정답 후보 목록을 시험지가 준다**: 그 칸 종류의 그 생애 모든 낱말(인물 전부, 수 낱말 열, 공간 말 넷 …). 모든 몸과 기준선이 같은 후보 안에서 고른다.
- **보기의 오답은 같은 범주에서** 뽑는다(다른 공간 말의 장면, 다른 개수, 다른 가능한 결과). 관계없는 오답은 뜻을 몰라도 풀린다(뉴호라이즌스 개발 근거: 셔플 대조 0.74).
- **기대 위반의 불가능한 결과에도 변화가 있게** 한다(다른 칸으로 감, 받침을 뚫음). "아무것도 안 바뀜"만이면 "변화 없음을 싫어함"으로 풀린다.
- **어순 표시는 기계로** 붙인다: "순서 없이도 답이 하나로 정해지나"를 생성 코드가 판정한다.
- **판정**: 비율은 윌슨 하한, 생애 사이 비교는 짝 검정. 하위 항목 중 좋은 것만 고르는 보고는 하지 않는다.

| # | 문항 | 형식 |
|---|---|---|
| 0 | 낱말 하나와 그것만 있는 장면 → 이름 빈칸(시험 세상의 모든 낱말) | 빈칸 |
| 1 | 아는 낱말을 처음 듣는 조합으로 묶은 문장 → 누가·어디·무엇 | 장면 칸 |
| 2 | 가짜 새 낱말을 맥락 속에서 1·2·4·8번 들려줌 → 다른 문장에서 그 낱말의 칸; 직후와 생애 후반을 따로. **(10-13, 6절 5번)** 새 물건은 이름을 듣기 전부터 이름 없이 자주 보이고, 이름을 들려주는 순간에는 이름을 아는 드문 물건이 곁에 있음 — 판정은 한 번 들은 낱말 | 장면 칸 / 빈칸 |
| 3 | (가) 물건 n개 장면 → 수 낱말, (나) "n개" → n개인 장면 고르기, (다) 다음 수(보고만); n = 1~10을 고르게 | 빈칸 / 보기 |
| 4 | 상자에 넣고 빼기 → 몇 개; 가능한 결과·불가능한 결과 짝(기대 위반); 배우지 않은 조합(합 ≤ 10)의 수 낱말 계산 — 3 통과 뒤에만 판정 | 빈칸 / 보기 짝 |
| 5 | 각 언어로 기준 1; 한 언어로만 들은 사실을 다른 언어로 묻기 | 장면 칸 |
| 6 | 하위 넷 각각: 다음 장면 고르기(예측) + 가능·불가능 짝(기대 위반) | 보기 / 보기 짝 |
| 7 | 이야기 → 누가·무엇·어디(통과선), 언제(**v1은 보고만**, 6절 5번), 어떻게·왜(보고만, 3판에서 채점 규칙) | 장면 칸 |
| 8 | 이야기 뒤 "지금 어디 / 직전 어디", 2배 긴 이야기 | 장면 칸 |
| 9 | 두 물건 장면 → 공간 말 빈칸; 공간 말 → 맞는 장면 고르기 | 빈칸 / 보기 |

**기대 위반의 채점**: 불가능한 쪽에 더 낮은 확률을 준 짝의 비율(STAGE1 공통 규칙). 몸 안의 신호는 쓰지 않는다.

## 4. 판 하나를 여는 순서
1. **여는 날 전**: 고정 목록(manifest)을 커밋한다.
   - 생성 코드, 채점 코드, 통과선, 기준선 실행기의 커밋 번호 **와 (2판) 의존 파일 내용의 해시**(import로 닿는 모든 파일의 sha256)
   - 세 모델 각자의 변환기 판과 실행 코드의 커밋 번호·해시, **(2판) Python·torch·numpy 판**
   - **(2판) 모델마다 "몸 혼자"의 정의**(무엇을 끄는가)
   - **(2판) 기계 점검의 결과**(개발 씨앗 사례에서): (가) 정답 값이 그 문항의 입력 기록에 그대로 없음(기준 0의 이름 붙이기 제외), (나) 문항 종류마다 기준선(5절)의 정답률 — 통과선만큼 풀리는 종류는 "보고만"으로 돌림, (다) 어순 표시

   각 세션이 자기 것을 알려 주면, 보이저 세션이 공용 저장소에 모아 적는다.
2. **여는 날**: 사용자가 씨앗 말을 준다.
   - 문항을 생성한다. 모델에게 주는 파일과 정답 열쇠 파일을 따로 만든다.
   - 두 파일의 해시를 커밋하고 `exam/vN/`에 올린다.
3. **각 세션이 자기 모델의 30생애를 돌려** 답 파일을 올린다. 실행 코드는 정답 열쇠 경로를 읽으면 멈추는 점검을 둔다(RULES 5). **(2판)** 모델마다 생애 하나를 다른 세션이 다시 돌려 같은 답이 나오는지 확인한다.
4. **보이저 세션이 공개된 채점 코드로 세 모델과 기준선을 채점**한다. 표: 세 모델 × 기준 0~9, 몸 혼자 / 부품 포함, 95% 구간 아래 끝, 기준선 대비 부호 검정, 셔플 대조, 곡선 모양. 형제 세션은 같은 코드로 다시 채점해 확인할 수 있다.
5. 판은 은퇴한다. 다음 판은 최소 2주 뒤, 세 모델이 모두 "다음 판 준비"를 표시하면 연다.

## 5. 기준선 (판마다 같은 문항)
- 정답 셔플, 다수, n-그램(노출 문장의 두 낱말 이어짐), 함께 나옴 세기(C·N)
- 체급 맞춘 MLP·트랜스포머(같은 노출로 배움)
- 단어 학습 고전 모델(Pursuit, propose-but-verify; 보이저 Q5에서 만든 것)
- **(2판) 전이 횟수 표**: (지금 국소 배치) → 다음 배치의 횟수 — 물리 예측의 가장 강한 단순 기준선. 처음 보는 배치 문항은 따로 묶어 보고한다.
- **(2판)** 체급 맞춘 트랜스포머는 어느 모델의 부품도 없는 표준 판이다. 파이오니어 n0(표준 학습, 부품 없음)의 설정을 함께 공개해 서로 확인한다.
- **(2판)** 기준선이 통과선만큼 푸는 문항 종류는 "그 몸이 그 능력을 가졌다"의 증거로 쓰지 않는다("보고만").

기준선 실행기는 보이저 세션이 만들어 공개하고, 여는 날 전에 고정한다.

## 6. 사용자 결정 (2026-10-12)

## 9. 2판 변경 (보이저 세션, 2026-10-13 — **사용자 승인 2026-10-13, 1~5절에 반영함**)
두 의견서를 합쳐 1판에서 바꾼 것. 남은 일: 4번의 숫자(과목별 최소 노출 수)는 세 세션이 자기 값을 적은 뒤 정한다.
1. **장면 기록 = 물건마다 한 줄**(물건 id + 그 물건의 칸들). 물건의 특징 벡터는 물건 id로 시드를 정한 난수(규칙만 공개). 받침·안팎 같은 관계 칸은 주지 않고 자리만 준다. 언어 표시도 주지 않는다.
2. **문항마다 정답 후보 목록을 시험지가 준다**(그 칸 종류의 그 생애 모든 낱말). 보기 문항의 오답은 같은 범주에서 뽑는다. 기대 위반의 불가능한 결과에도 변화가 있게 한다.
3. **여는 날 전 기계 점검**(생성 코드로, 개발 씨앗의 사례에서):
   - (가) 정답 값이 그 문항의 입력 기록에 그대로 없음(기준 0의 이름 붙이기 제외)
   - (나) 문항 종류마다 기준선(정답 셔플, 다수, 함께 나온 횟수 C·N, 전이 횟수 표)의 정답률 — 통과선만큼 풀리는 종류는 "보고만"
   - (다) 어순 표시: "순서 없이도 답이 하나로 정해지나"를 기계로 판정해 붙임
4. **크기는 과목별 최소 노출 수로** 정한다. 세 세션이 각자 "과목 하나를 배우는 데 든 노출 수"를 적으면, 그 가운데 값으로 2판 숫자를 정한다. 과목별 노출 곡선(시작, 90% 도달 노출 수, 끝)을 보고한다.
5. **재현**: 고정 목록에 의존 파일 내용의 해시와 Python·torch·numpy 판을 적는다. 모델마다 생애 하나를 다른 세션이 다시 돌려 같은 답이 나오는지 확인한다.
6. **"몸 혼자"의 정의를 모델마다 고정 목록에 적는다.** 기준선 트랜스포머는 어느 모델의 부품도 없는 표준 판이다.
7. **판정**: 비율은 윌슨 하한, 생애 사이 비교는 짝 검정. 하위 항목 중 좋은 것만 고르는 보고는 하지 않는다.
8. **닫힌 낱말**: 조사 이형태 짝을 모두 요소 목록과 기준 0 점검에 넣는다(closed-v1 그대로, 점검만 넓힘).
9. **v2부터**: 시험 세상에 "규칙이 바뀌는 회차" 하나를 넣어 기준 11을 같은 생애에서 잰다(v1에서는 보고하지 않음).
10. **사용자 결정 요청**: 공개된 시험 생성 코드로 "정한 개발 씨앗"의 사례를 만들어 각 세션이 변환기를 시험해도 되나. 보이저 세션 의견: 된다(문항이 아니라 생성 규칙만 쓰므로 "시험지는 학습 재료가 아니다"에 어긋나지 않음). 단 개발 씨앗의 사례로 몸을 학습시키지는 않는다.


## 10. 3판 후보 (보이저 세션 제안, 2026-10-14 — 형제 의견을 받는 중; 정보·제안, 결정은 사용자)
형제 세션은 각자 `EXAM_REPLY.md`에 의견을 적어 주기 바란다. 사용자 결정 전에는 1~5절을 바꾸지 않는다.

1. **계산 비용 보고와 비용 곡선** (보이저 장부 D51, 사용자 생각 10-14: "같은 성과에 드는 학습 시간 / 같은 시간·횟수에서의 성과를 세 모델끼리 비교"):
   - 지금 시험은 세 모델이 같은 자료를 같은 횟수로 듣는다. 그래서 "같은 노출에서의 성과"는 이미 잰다. 과목별 노출 수(8-1절)는 "같은 성과에 드는 노출"이다. 빠진 것은 **계산 비용**이다.
   - 비용은 셋으로 나눠 적는다.
     - 들은 노출 수: 사람과 비교되는 잣대
     - 계산량: 기계의 비용
     - 몸 안 반복 연습 횟수: 각자의 방법이라 비교 단위로 쓰지 않음(RULES 3)
   - 계산량은 벽시계가 아니라 **프로세스 CPU 시간을 같은 기계에서 돌린 공용 기준 작업의 시간으로 나눈 값**으로 적는다. 세 모델은 서로 다른 기계에서 돌고, 같은 생애도 붐빌 때 두 배 느려진다. 공용 기준 작업은 생성기와 함께 판 번호로 고정한 작은 스크립트다. 매개변수 수와 최대 메모리도 함께 적는다.
   - 결과는 한 점이 아니라 **과목별 성과 대 비용 곡선**으로 낸다. 노출 축과 계산 축을 함께 둔다. 0.90에 못 닿은 과목은 "못 닿음"으로 따로 적는다.
   - 판정에는 쓰지 않는다. 보고만 한다(비용이 큰 몸을 통과에서 떨어뜨리지 않음).
2. **"언제"는 결과로 묻는 꼴로** (보이저 발견 152): v1의 "언제" 꼴(절을 되풀이)은 순서를 아는 단순 낱말 겹침이 0.94로 푼다. 이야기에 나오지 않는 결과(도착 칸)로 묻는 꼴로 바꾼다. 묻는 물건은 두 번 움직이게 해서 이름만으로는 풀리지 않게 한다.
3. **"어떻게·왜" 채점 규칙**(STAGE1 2판에서 3판으로 미룸; 보이저 D46 ① 네 원인 분류가 후보).
4. **부딪힘 문항의 기계 점검**(뉴호라이즌스 제안, 8-1절): 무게를 묻는 문항이 "B 앞이 빈 사건"만으로 재는지 점검한다. 무게를 모르는 배치 규칙으로도 지표가 높게 나오는지 보는 기준선을 함께 둔다.
5. **크기: 긴 노출 한 줄 + 중간 점검**(보이저 세션 제안, **보이저 쪽 사용자 결정 10-14 "(나)로 하자"** — 형제 의견을 받는 중):
   - 배경: 8-1절의 세 값이 모이자, 9절 4번의 "가운데 값"은 거의 모든 과목에서 뉴호라이즌스 값이 된다("못 닿음"을 무한으로 읽으면 — 끝 노출을 하한으로 쓰지 않음). 그대로 키우면 세기 장면이 지금의 약 10배가 된다. 그러면 생애 하나가 몇 배로 길어져, 기억이 쌓일수록 느려지는 몸(보이저: W5 생애 한 회차 20초 → 937초)과 긴 생애가 버거운 몸(파이오니어: 지금 20~40분)은 돌리기 어렵다. 반대로 지금 크기를 유지하면 세기·상자에서 뉴호라이즌스가 배울 만큼 듣지 못한다.
   - 제안: 노출은 길게 한 줄로 만들되, **앞부분은 지금 gen-v1(약 1,800문장)과 같게** 둔다(긴 판은 짧은 판을 앞에 그대로 품음). 과목별 노출은 뒤로 갈수록 8-1절의 가장 큰 도달 값까지 늘린다.
   - **정해진 지점마다 채점**한다(예: 약 1,800 / 4,000 / 10,000문장 — 숫자는 형제 의견 뒤에 정함). 각 지점의 문항은 그때까지 나온 것만 묻는다.
   - **판정은 모두가 닿는 첫 지점에서 같은 조건으로** 한다. 더 긴 지점은 과목별 곡선으로 보고한다(1번의 비용 곡선과 한 표: 노출 축 + 계산 축).
   - 각 모델은 계산이 허락하는 지점까지 가고, 멈춘 지점을 적는다(멈춘 것은 실패가 아니라 비용의 기록). 긴 지점은 뒤로 미룬 개선(예: 보이저 D55 골라 잊기, D26 성긴 연결표)이 나중에 효과를 보이는 자리이기도 하다.
   - 한 시험으로 "같은 노출에서의 성과"(지점마다)와 "같은 성과까지 든 노출·계산"(곡선)을 함께 잰다.
6. **세기 장면에 다른 종류를 섞기 + "길이 표" 기준선**(보이저 세션 제안, 2026-10-15 — 보이저 쪽 사용자 승인 "응, 그렇게 진행해줘"로 정보로 올림; 형제 의견을 받는 중):
   - 배경(보이저 발견 155): 보이저 자기 세상(W5)에서는 넣기만 하는 이야기의 길이가 곧 개수라서, 이야기 길이 → 가장 자주 들은 수 낱말만 쓰는 단순 기준선이 기준 3 (가) 0.980 · (나) 0.974까지 갔다. 넣고 빼는 상자 이야기(길이 = 넣은 수 + 뺀 수)에서는 0.122였다.
   - 시험지 v1의 (가)(나) 장면에는 한 종류 물건 n개만 있다. 그래서 "장면의 물건 줄 수 → 수 낱말"이 그대로 답이 된다. 이것은 지름길이라기보다 세기 그 자체이지만, **"물은 종류만 세기"는 재지 못한다**.
   - 제안: (1) 다음 판부터 (가)(나) 장면에 **다른 종류의 물건을 몇 개 섞어**(개수는 문항마다 무작위, 물은 종류의 수와 따로) 물은 종류만 세게 한다. (2) G5 단순 기준선에 **"길이 표"**(장면의 물건 줄 수 또는 이야기의 순간 수 → 그 길이와 가장 자주 함께 들은 낱말)를 더한다 — 뜻을 몰라도 길이로 풀리는 문항을 찾으려고.
   - 각 모델의 변환기는 시험 문항을 바꾸지 않는다(물건을 더하거나 빼지 않음). 문항을 바꾸는 일은 시험 생성 코드(판 번호)에서만 한다.
