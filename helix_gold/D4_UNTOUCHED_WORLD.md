# 손대지 않은 새 세상 — 설계 고정 (장부 D4, 2026-10-09)

사용자 결정(2026-10-08): 손대지 않은 세상 = **새로 만드는 세상**. 조정(2026-10-09): **설계는 D13 다음에 먼저 고정**하고, 실행은 ④+ 핵심 지식
묶음이 끝나는 마디에서. 이 문서를 고정한 뒤에는 이 세상의 결과를 보고 부품을 고르거나 설정을 바꾸지 않는다. 고치면 이 세상은 "본 세상"이 되고 다음 세상을 새로 정한다.

## 쓰는 법
- 설계·판정에 쓰지 않는다. 1단계 경로의 마디마다 "본 세상들과 **같은 방향**으로 나아지나"만 기록한다.
- 비교: 그 마디의 채택 부품을 모두 켠 몸 − 끈 몸, 같은 시드 규칙(30 → 100). 같은 방향이 아니면 특화의 신호로 기록하고, 원인은 본 세상에서 찾는다.
- 이 문서의 내용은 지금 만든 부품의 시험 결과를 보지 않고 정했다(발견 126~136은 아직 30시드 결과가 없음).

## 같은 능력, 다른 겉모습

| 능력 (본 세상) | 새 세상에서 바뀌는 겉모습 |
|---|---|
| 격자 5×5, "나" 기준 좌표 | **6×4 직사각형**(가로 6, 세로 4). 먼저 기억 점검(요소 기억이 모든 칸을 알아보나) — 못 하면 크기만 5×5로 되돌리고 그 사실을 기록 |
| 움직임 낱말 5개(위·아래·좌·우·대각) | **다른 묶음 4개**: 오른쪽 두 칸, 왼쪽 한 칸, 오른쪽 위 대각, 아래 한 칸. 새 낱말(무작위 특징) |
| 거꾸로 방(위아래 뒤집힘) | **좌우 거울** 방 |
| 한국어 조사(가 / 에서 / 를) | 같은 역할의 **다른 조사 토큰**(새 무작위 특징) — 역할 구조만 같음. 시작 조사가 문장 안에서 놓이는 순서도 다르게 섞음 |
| 여러 순간 이야기(GO, EODI) | 같은 구조, 새 토큰. 이야기 길이 2~4 순간(본 세상은 2~3) |
| 장면 → 동사, 장면 → 문장 | 같은 시험, 새 낱말 |
| 물체 성질(단단함·밀림) + 기대 위반 | 성질 이름과 값의 조합을 새로(방마다 물체 수 3~6개, 본 세상은 4개 고정) |
| 중력(아래로, 받칠 때까지) | **왼쪽 벽 쪽으로** 끌림(방향만 다름) |
| 담김(안 / 옆) | 같은 구조, 새 토큰 |
| 작은 수 1~3 + 다음 수 노래 | 새 수 낱말 4개, 노래 구조 같음 |
| 수직선(D13) | 세로 줄(위로 갈수록 큼) |

## 고정하는 수치
- 난수 줄기: 모든 생성에 `seed * 7907 + 방 번호 + 41_000_000`대의 새 줄기(본 세상들과 겹치지 않음).
- 방 수 32, 회차 16, 들은 문장 수·시험 수는 본 세상과 같은 규칙(HEARD 6, TEST 3) — 다른 것은 겉모습만.
- 학습자·설정: 그 마디에 채택된 몸 그대로(이 세상을 위해 바꾸지 않음).

## 만드는 때
- 생성기(`data_untouched.py`)는 ④+가 끝나는 마디 직전에 이 문서대로 만든다. 만든 뒤 하는 것은 "생성되나 / 기억 점검" 두 가지뿐이고, 학습 결과는 마디 판정 때 처음 본다.
