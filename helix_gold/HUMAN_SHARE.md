# 다미(코드네임 보이저)의 사람 몫 표 (2026-10-15, 장부 D67)

사용자 결정(10-15, 시아 세션의 대화에서 이어짐): 사람의 몫은 두 갈래다.
- **구조·설계·로직의 몫**: 뉴런의 화학작용이나 전기 흐름 같은 바탕이다.
- **학습의 몫**: 배우는 동안 사람이 정해 주는 것이다.

사용자의 정정(같은 날): "우리가 말하는 몸이 사실은 일부 부품까지 포함된 하나의 뇌로서 작동되는 몸 … 판단은 여러 기능이 같이 작동해야 의미가 있고, 그건 마치 DNA와 같은 거라 인간이 만든 거든 아니든 상관없이 있어야 하는 구조 … 모델 스스로 대체하기에는 RSI에 가까운 너무 큰 재귀개선 … 그래서 지금 해야 할 일이 아니다."

**그래서 이 표의 원칙**
1. **뇌(1절)는 DNA다.** 몸의 바탕과 핵심 부품이 함께 하나의 뇌로 돈다.
   - 누가 만들었든 있어야 하는 구조이고, 지금은 줄이거나 다미 스스로 바꾸게 하지 않는다(아주 나중의 일).
   - 이 표는 투명하게 밝히려는 것이지, 빼려는 것이 아니다.
2. **판정은 뇌 전체(부품 포함)로 한다.** "몸 혼자"(월드모델 침묵, D21)는 앎이 뇌의 어디에 있는지 보는 진단으로만 쓴다.
3. **지금 줄이는 것은 학습의 몫(2절)뿐이다.** 사람이 정해 주던 배우기의 선택을 다미 자신(방법 층)이 하게 한다.
4. **새 부품은 일반 원리로만 더한다**(D50, 사용자 10-15 "테스트에 최적화된 로직을 설계하는 실수는 경계").
   - 과목 하나를 풀려고 짠 절차는 더하지 않는다. 뇌를 늘리는 일은 DNA를 바꾸는 일이라 1단계 뒤 관문(D49와 같은 자리)에서 본다.
   - 그래서 장부 D61(말로 들은 개수를 월드모델 상태로)은 보류다.

**두 층의 시험(사용자 10-15, D67 덧붙임)**: 1절은 **바깥 시험 = 진화**의 산물이다. 우리가 조건을 겨뤄 기본값으로 채택해 온 것으로, 변이 → 환경 → 선택이고 사람 몫은 정당하다. 2절은 **안쪽 시험 = 한 생애의 배움**이고, 사람 몫을 줄일 곳이다. 두 층 사이의 다리는 볼드윈 효과다(방법 층이 늘 같은 선택을 하면 그것을 기본값으로 올림).

## 1. 뇌 — DNA로 주어진 구조 (지금 손대지 않음)
| 부품 | 하는 일 | 그 덕에 풀리는 것(발견) |
|---|---|---|
| 요소 기억(Module A) | 입력을 먼저 그대로 외움 | 기준 0(146) |
| 버릇(`KnowDo2`) | 맥락 → 비슷한 낱말 + 연결표 | 들은 짝, 처음 듣는 조합의 바탕 |
| 연결 기록(`DirectionalHebbian`) | 함께 나온 횟수 | 처음 듣는 조합 |
| 틀(`PatternMemory`, `CuedPatterns`) | "A → B" 방향을 벡터 차이로 옮겨 씀 | 움직임 동사, 축척(153) |
| 통째 기억(`ChunkMemory`) | 들은 문장을 그대로, 비슷한 것을 꺼냄 | 한 번 들은 짝 |
| 위치 기억(where 채널) | 자리를 정확히 저장 | 칸 답 전부 |
| 시간 묶기(순간) | 같은 때 온 토큰을 한 순간으로 | 모든 문장 |
| 월드모델 책(`+wm`) | 움직임 낱말의 이동을 기록에서 셈 | 연쇄(145), 굴림 |
| 확신한 월드모델이 마지막에(`+wmlast`) | 확실할 때 답을 정함 | 조사 이야기 0.41 → 1.00(125) |
| 맥락 책(`+wmctx`) | 방의 뒤집힘을 못 들은 동사에도 | 거꾸로 방(122) |
| 조사 묶기(`+bind`) | 조사를 바로 앞 낱말에 | 한국어 조사 이야기(123) — 영어식은 못 함(W6 예상) |
| 따라가기(`+track`) | 물건마다 상태를 순간마다 | 여러 순간 이야기(126), 기대 위반 |
| 세기(`+count`) | 상자 안 개체 수 → 수 낱말 | 수 1~10, 넣고 빼기(133·155) |
| 세는 노래의 차례(`+succ`) | 노래에서 다음 수 | 넷 세기(134) |
| 중력·받침(`+grav`), 담김(`+contain`) | 물리 규칙 | 기준 6(130·132) |
| 축척(`+scale`) | 수직선의 비율 | 뺄셈(153) |
| 시점(`+views`·`+vturn`), 목표(`+goal`), 나(`+self`) | 기준틀·목표·자기 | 발견 137~140 |

- 이 뇌의 몫이 지금 시험 통과의 대부분이다. 예: 발견 155의 수 1~10은 뇌 전체 1.000, 월드모델을 끈 진단 값은 우연 근처였다. 시험 표(W7)에는 이 표를 곁에 두고 "어느 부품 덕인가"를 함께 적는다(D64의 출력창도 같은 칸).

## 2. 학습의 몫 — 지금 사람이 정해 주는 것 (줄일 곳)
| 사람이 정하는 것 | 지금 | 다미가 스스로 하게 하는 길(후보) |
|---|---|---|
| **어느 부품을 켤지** | 실험마다 조건 이름(`+count`, `+track` …)으로 사람이 고름 | 방법 층이 세상을 보고 켜고 끔. 이미 "깨우기"(`+wake`) 손잡이가 일부 부품을 켜고 끔 → 넓히기. W7은 우선 "그 세상의 모든 부품을 켬" |
| 무엇을 복습할지 | 방법 층의 고르기(놀람 / 진척, 발견 41·156) | 이미 다미가 고름. 신호를 낫게(D35, D58) |
| 얼마나 연습할지·학습률 | 방법 층 손잡이 + 사람이 정한 범위 | 범위 자체를 기록에서(D52) |
| 무엇을 잊을지 | 없음(다 남김) | 골라 잊기(D55: 원본은 두고 쓸 때 끔) |
| 어떻게 연습할지(외우기 대 일반 규칙) | 들은 그대로 연습 | 기호 바꿔 보기 놀이(D62, "놀이" 출처 표지) |
| 부품의 답을 몸으로 넘길지 | 사람이 정한 거름(D25 1판) | D25 2판(몸의 표현이 바뀐 뒤) |
| 새 규칙을 언제 만들지 | 사람이 실험을 짬 | 지루함 고리(D58 (라)·(마)) |
| 무엇을 물을지 | 사람이 시험 문항을 짬 | 의문사 세분화(D35 (다)) |

- **세상**(무엇을 듣나, 교과서 공식, 방 순서)은 배우는 이의 몫이 아니라 환경이다. 시험과 같은 공용 교재(D23)로 세 모델에 똑같이 주므로, 이 표에 넣지 않는다.

## 3. 트랙 B 순서에 주는 것
- 먼저 2절(학습 쪽): D62 놀이 → D55 → D25 2판 → D58 → D44(새 낱말 편향 — 배우기의 기울기) → "부품 켜기를 다미가".
- 1절을 바꾸는 일은 1단계 뒤 관문에서 본다: D49(관계 엔진 다시 설계), D26(체급), D61(말로 들은 개수), W6 영어식을 위한 `+bind` 손질.
  - 그때까지 영어식·건너 묻기는 "아직"으로 적는다.
