## 검토할 것 (각 세션이 한 번)
1. **자기 모델에 관한 사실**: 결과 수치, 조건, 판·지문, 시간, 인용한 읽기가 자기 기록과 맞는가. 틀리면 맞는 값과 근거 파일을 적는다.
2. **시험 방법**: 생성기, 열쇠 봉인, 씨앗 말, 채점기, 기준선, 통과선 설명이 맞는가.
3. **주장의 크기**: 증거보다 큰 주장이 있는가. 특히 "왜"에 관한 문장 가운데 재지 않은 것이 있는가.
4. **빠진 것**: 한계, 관련 연구, 꼭 넣어야 할 자기 쪽 결과나 주의.
5. **틀과 읽기 쉬움**: 절 순서, 표, 그림에 대한 제안.

## 검토 파일 꼴
- 한국어로 쓴다. 고칠 문장은 영어 원문을 그대로 인용한다.
- 항목마다 다음을 적는다.
  - **위치**(절 번호 또는 인용).
  - **종류**(사실 틀림 / 주장 큼 / 빠짐 / 제안).
  - **고칠 내용**과 **근거**(파일·커밋).
- 맨 위에 검토한 초안의 커밋과 날짜를 적는다.

## 차례
1. 다미 세션이 초안을 `paper1/DRAFT.md`에 올리고 `STAGE1.md`에 알린다.
2. 각 세션이 다음 형제 읽기 때(또는 사용자가 말할 때) 한 번 검토한다. 아라·시아는 자기 저장소의 `PAPER1_REVIEW.md`에 쓰고, 다미 세션이 옮긴다. 다미는 `paper1/REVIEW_dami.md`에 쓴다.
3. 다미 세션이 검토를 모아 고친다. 고친 것과 고치지 않은 것(이유 포함)을 `paper1/CHANGES.md`에 적는다.
4. 사용자가 확인한다.
5. 공개 준비로 넘어간다. 저자는 사용자다. Claude 세션들이 코드와 글 대부분을 만든 것은 방법 절에 밝힌다.
