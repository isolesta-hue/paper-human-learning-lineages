2. **빠진 열쇠**(시험만 넓히고 부품은 그대로; 회귀는 정확히 같음 + 시드 0 시험) — **진행 10-16**: 기준 8은 새 세상 `@c8`(= `@multi` + "[A ga] JEONE EODI" 직전 어디 — 들려주는 예시로 JEONE을 배움, 답은 "at" 칸이라 따라가기 부품의 신뢰 기록에 섞이지 않음 — + 4~6절 긴 이야기 시험) + 셔플 `@c8shuf`; 옛 세상 26종 × 시드 3 바이트 같음, `@c8`은 `@multi`를 그대로 품음, 문항 4,140개 독립 모의로 문제 없음(`check_c8_*.out`). 생애 회귀·시드 0 시험은 예비 시험 뒤. 기준 6은 네 영역 모두 예측 + 기대 위반 열쇠가 이미 있어 실행기에서 같은 꼴로 묶기만 함(중력·받침 `grav floor`·`grav stack` / `voe float`, 담김 `contain in`·`contain by` / `voe inside`·`voe beside`, 단단함·밀기 `objs hit` / `voe solid`·`voe push`, 영속성 `multi` / `voe permanence`·`voe identity`). 기준 1·7의 누가·무엇: 다미 세상에는 행위자(인물)가 없어 "누가(행위자)"와 "무엇(대상)"을 나눌 수 없다 — 지금은 주어 묻기(W6 "무엇")와 어디로 재고, 행위자가 있는 세상은 따로 제안:

   - 기준 8: 직전 어디 + 2배 긴 이야기
