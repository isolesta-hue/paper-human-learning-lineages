# D22 설계 — 틀(동화)과 현실 구별: 현실 앵커 + 여러 꼬리표 (2026-10-10, 설계; 만들기는 이 문서를 고정한 뒤)

## 사용자 생각 (2026-10-10)
- 사람은 동화·영화·게임·만화를 현실과 분명히 구별하면서도 그 안의 이야기를 이해한다. 이건 어떤 구조와 로직인가.
- 이것도 앵커와 기준이 필요하다. 기준이 되는 **'가장 현실에 가까운 월드모델'**이 있어야 하고, 그 월드모델의 꼬리표와 **'나' 벡터**를 포함한
  **여러 꼬리표가 동시에 앵커**가 되어야 틀이 섞이는 환각이나 분류 경계 붕괴를 막는다.

## 사람 쪽 근거 (원리만)
- 분리 표상(Leslie 1987): 가장놀이의 "바나나 = 전화"는 현실 표상을 덮어쓰지 않고 따로 표시된 사본에서 돈다.
- 범위 문법(Cosmides & Tooby 2000): 들은 정보에 "어디까지 참인가"의 범위 꼬리표를 붙이고, 꼬리표가 떨어지면 오염(믿음으로 새어 나감)이 생긴다.
- 출처 감시(Johnson 1993): 기억이 어디서 왔는지(본 것 / 들은 것 / 상상한 것)를 판단하는 과정; 출처 혼동이 거짓 기억의 한 원인.
- 영상 결손 효과(D24): 내 행동에 반응하지 않는 것은 '구경하는 틀' — 수반성이 현실의 강한 표지.

## 보이저에 이미 있는 것
- 방마다 책(발견 122 `+wmctx`, 131 `+wmframe`: 방의 틀 = 정사각형의 8 대칭) — 거꾸로 된 방에서는 **모든** 움직임 낱말이 함께 돌아감.
- 중력 세계 `@grav`(발견 130): "falls"는 막힐 때까지 내려감, 거꾸로 된 방에서는 위로(진짜 방의 규칙).
- 출처 축(발견 84·85): 직접 들음 / 되돌려 봄 / 추론 / 스스로 만듦 — 기억의 한 축.
- '나'의 수반성(`+self`, 발견 140): 내 행동에 반응하는 것을 8 대칭 중 하나로 찾음.
- D21: 자기 평가는 몸 혼자로(이 설계의 판정도 몸 혼자 점수와 부품까지 점수를 따로 기록).

## 1판 세상 `@tale` (= `@grav` + 동화 이야기; 다른 세상은 그대로, 새 토큰은 마지막에, 따로 난수 흐름)
- **동화 이야기**: 보통 방(거꾸로 아님)에서, 이야기 맨 앞에 표지 낱말 `YENNAL`("옛날 옛적에"). 동화 안에서는 **"falls"만 위로**(마법) — 다른 움직임
  낱말은 그대로. 즉 방 전체가 돈 것이 아니라 **규칙 하나의 예외**(거꾸로 된 진짜 방과 겉보기 결과는 같지만 모양이 다름).
- 동화는 **진짜 이야기와 같은 방·같은 물건**에서 일어난다(방마다 책이 이미 있으므로, 다른 방이면 오염 시험이 안 됨).
- **표지 빠짐**: 동화 이야기의 1/3은 표지 없이 들림(아이가 "옛날 옛적에"를 못 들은 경우). 이때 남는 단서 = 현실 앵커와의 어긋남 모양(한 낱말만
  뒤집힘 vs 방 전체 회전).
- **동화에서만 처음 듣는 물건 이름** 몇 개(전이 시험: 낱말은 현실로 건너와도 됨).
- 시험: 진짜 질문(표지 없음)과 동화 질문(표지 있음)을 같은 방에서 따로.

## 비교 조건 (1판, 30시드 → 100시드 규칙)
| 조건 | 내용 |
|---|---|
| `Tn` 꼬리표 없음 | 표지는 그냥 낱말 하나 — 방의 책이 동화까지 모두 배움 |
| `T1` 꼬리표 하나 | 표지 있는 이야기만 '동화 책'으로, 나머지는 현실 책으로 |
| `TA` 앵커 + 여러 꼬리표 (사용자 설계) | 현실 앵커 = 표지 없고 앵커와 맞는 직접 경험으로만 만든 책. 동화 = 앵커 + 예외(차이)로 담음. 동화 판정은 표지 **또는** 앵커 어긋남 모양(한 낱말만 뒤집힘) — 꼬리표 여럿이 동시에 |
| `Ti` 동화 무시 | 표지 있는 이야기를 버림(오염은 없지만 이해·전이도 없음) |

## 사전 등록할 측정 (만들기 전에 고정)
- **D22-1 오염**: 동화가 들린 방의 진짜 "grav floor/stack" 정확도 — 예상: Tn이 가장 낮음.
- **D22-2 틀 안 이해**: 표지 있는 동화 질문 정확도("falls" 위로) — 예상: Ti 가장 낮음, T1 ≈ TA.
- **D22-3 표지 빠짐에 버티기**: 표지 없이 들린 동화가 있던 방의 진짜 질문 정확도, TA − T1 — 사용자 가설의 핵심(여러 앵커가 경계 붕괴를 막음).
- **D22-4 거짓 동화 판정**: 진짜 거꾸로 된 방(방 전체 회전)의 중력 정확도, TA − T1 ≈ 0 — 놀라운 현실을 동화로 잘못 분류하지 않는가.
- **D22-5 전이**: 동화에서만 들은 물건 이름이 진짜 질문에서 쓰이는가 — 예상: Ti 가장 낮음.
- **D22-6 다른 측정**(이야기·처음 듣는 조합·연쇄): 조건 간 차이 ≈ 0.

## 이것이 가정하는 것 (확장 때 고칠 곳)
- 2D 격자, 마법 규칙은 하나("falls" 뒤집힘), 표지는 이야기 맨 앞의 낱말 하나.
- 동화와 현실이 같은 방·물건을 공유(현실의 아이 경험과 같음).
- **'나' 벡터 없음** — 1판의 앵커는 표지 + 앵커 어긋남 모양 둘. 2판: `@self`와 합쳐 "내 행동에 반응하는가"(수반성)를 셋째 앵커로
  (동화·영상은 내 행동에 반응하지 않음 — D24와 연결).
- 판정 규칙(한 낱말만 뒤집힘 = 동화)은 사람이 준 몫. 2판 후보: 어긋남 모양을 스스로 배우게.

## 1판 수정 계획 — "이야기로만 아는 방" (예측을 먼저 적음, 2026-10-10)
사용자 가설(여러 앵커가 환각을 막는다)이 시험되려면 **현실 다수결이 아직 없는 곳**이 필요하다 — 아이가 달·용·바다를 직접 보기 전에 이야기로 먼저 듣듯이.
- 세상 추가(`@tale` 안에서만, 따로 난수): 보통 방 c의 동화 2개를 **더 이른 방(c − 2)의 회차에** 들려줌(미리 듣는 이야기). 절반의 방은 표지 없이.
  시험 "tale preview": c를 아직 직접 겪기 전(c − 2는 봤고 c는 아직)인 회차에 c의 진짜 중력 질문(표지 없음; 정답 = 아래).
- 예측: Tn·T1(꼬리표 하나)은 표지 없이 미리 들은 방에서 **위로 답함(환각)** — 그 방의 책 항목이 동화뿐이므로. TA(앵커 + 여러 꼬리표)는 일반 앵커(다른 모든
  보통 방에서 "falls" = 아래, 이 방은 다른 낱말이 돌지 않음)와 어긋나는 모양으로 동화를 알아보고 **아래로 답함**. 표지 있는 미리 듣기 방에서는 T1 = TA.
- 부품 목표(1판): ① 틀 안 이해 — 표지 있는 질문에는 동화 책(현실 앵커 + 예외)으로 답함(지금 0.000), ② 이야기로만 아는 방의 환각 막기(위 예측),
  ③ 거짓 동화 판정 없음(진짜 거꾸로 된 방은 방 전체가 돌았으므로 현실). 몸 쪽 오염은 작아서(P1) 1판은 월드모델 쪽만, 몸 혼자 점수는 계속 기록.
- 부품 이름(조건 문자열 겹침 확인): `+tk1`(꼬리표 하나), `+tkA`(앵커 + 여러 꼬리표), `+tkig`(동화 무시).
