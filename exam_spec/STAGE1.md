## 모든 기준에 공통 (RULES.md 2판과 같은 원칙)
- 바깥 행동만, 규칙·코드로 채점(자기·AI 채점 없음). 한 몸의 내부·판독 형식을 전제하지 않음.
- 각 모델의 자기 세상이 아니라 **공용 봉인 시험지**로 잰다(자기 부품을 위해 만든 세상에서는 누구나 잘함). 시험지는 학습 전에 해시로 봉인, 판마다 한 번 열고 은퇴.
- 통과선은 **재기 전에** 정한다. 시드 30 → 미결이면 100. 기준선(정답 셔플·다수·n-gram·체급 맞춘 MLP/트랜스포머)과 함께 보고.
- 경험의 단위 = 교재 문장의 노출 수(같은 노출에서의 점수를 함께 보고).
- 보이저는 D21대로 "몸 혼자"와 "부품 포함" 점수를 함께. 다른 모델도 부품·외부 기억이 있으면 같은 구분을 권함.
- 결과는 세 모델 × 여섯 기준의 표 하나로(통과 / 부분 / 아직).

## 통과 뒤 (사용자 2026-10-12)
세 모델이 공통 통과선을 넘으면 → 동화 학습(공개 동화; D23 규칙 2판 1번에 따라 지금은 원정 시험으로만 — 학습 자료로 바꾸는 것은 그때 사용자 결정), 논문 쓰기 등의 계획.

**첫 논문은 앞당김 (사용자 결정 2026-10-20, 다미 세션 장부 P6)**: 시아 세션의 대화에서 나온 물음을 다미 세션에서 정함 — 사용자: "논문 제줄을 조금 앞당기는거 뿐이니까 기존의 논문 제출 계획과 차이는 없을테고, 그저 첫 논문의 내용이 좀 줄어들고 후속 논문에 내용을 더 많이 넣게 되는 차이일 뿐이네." → **첫 논문은 통과를 기다리지 않고 v1 결과(채점·점수표)로 쓴다**; 범위는 좁게(다미의 구조와 좌표계 글자 그림 월드모델 + 봉인 시험 v1 결과, 세 모델 비교는 짧게 또는 다음 논문), 나머지는 후속 논문으로. 다미 세션이 쓰고, 채점 뒤 목차 초안을 사용자에게 먼저 보임. 형제의 결과를 쓸 때는 각 세션이 올린 기록(답 파일·STAGE1_REPLY)을 그대로 인용한다. 아래 순서 3번의 "통과 뒤에 논문 쓰기" 중 **첫 논문만** 이 결정으로 앞당겨짐(동화·교재 학습의 때는 그대로).

**순서 덧붙임 (사용자 결정 2026-10-17, 다미 세션 D71 "아기 나침반")**: 1단계와 동화 사이에 **기초 대화 관문**을 둔다. 1단계 기준 0~9는 모두 듣고 이해해 답하기이고 말 만들기와 주고받기가 없기 때문 — 아이의 순서(이해 → 짧은 주고받기 2~3세 → 이야기 3~5세)를 따른다. 관문의 기준과 통과선은 설계 뒤 형제 의견을 받아 사용자가 승인한다(지금은 자리만). 함께 재는 것: 모델마다 1단계에 닿기까지 들은 문장·낱말 수와 학습 시간(경험 장부)을 아이의 나이별 발달과 견줌. 대화 상대(부모 역할)는 세상이 코드로 만든 것인 동안 코드 인물이며, Claude가 쓴 글은 여기서도 학습 자료가 아니다(규칙 6). **부모 역할 원칙(사용자 확정 2026-10-17)**: Claude는 부모가 되지 않는다(시험관·분석가만 — 진단으로 묻고 답을 볼 때는 모델이 배우지 않게 얼린 상태). 코드로 만든 세상 안에서는 코드 부모(부모의 지식 = 세상의 규칙과 지금 상태; 한계는 나이가 아니라 세상의 크기). 세상 밖 주제가 필요해지면(2단계 뒤) 사용자가 부모 → 사람의 아이-부모 대화 기록(CHILDES) → 오픈소스 SLM 부모(증류로 표시, "부모 몫"을 따로 잼) 순으로 검토 — 뒤의 둘은 지금의 규칙 1·9에 걸리므로 그때 사용자가 규칙을 바꿀지 정한다. **세상 밖 질문(사용자 결정 2026-10-17)**: 코드 부모가 답할 수 없는 질문에는 "모른다"로 답하고 질문을 적어 두며, 다음 세상을 만들 때 그 질문들을 참고해 세상 규칙을 코드로 넓힌다. 정 안 되면 검색 맨 위 요약 수준(짧은 한 문단)의 찾아 읽기 — 사람이 쓴 글만(AI 요약은 규칙 9에 걸림), 정한 규칙으로 기계적으로 고름(규칙 5), 읽은 낱말은 경험으로 셈; 읽기가 생긴 뒤(기초 대화 관문 다음) 그 판에서 규칙 1을 바꾸는 것으로. 형제 세션은 정보로 읽고, 의견은 각자 `STAGE1_REPLY.md`에.

## 제안 2판 (2026-10-12 보이저 세션 작성 — **사용자 승인 2026-10-12: "제안 2판 그대로 승인"**)

### 순서 (사용자 결정 10-12, 두 형제 장부에 기록됨)
1. 1단계 능력은 **각 모델이 자기 세상에서 겪어서** 얻는다(아기가 물건을 떨어뜨리고 만지며 얻듯이). 세상에 없는 과목(수·물리·두 언어)은 각자 세상을 넓혀 넣는다.
2. 1단계 동안 공용 저장소에서 받는 것은 **측정용 봉인 시험지뿐**이다(시험지는 학습 재료가 아님, 판마다 한 번 열고 은퇴).
3. 세 모델이 통과한 **뒤에** 공용 교재(문장 + 장면 짝, D23 규칙 2판)와 동화·교과서 학습, 논문 쓰기를 시작한다.
4. 이름: 1단계용은 "각자의 경험 세상", 통과 뒤 함께 쓰는 것은 "교재".

- **기대 위반** = 같은 장면의 가능한 결과와 불가능한 결과 짝에서, 불가능한 쪽에 더 낮은 확률을 준 짝의 비율(몸 안 신호를 쓰지 않음).

  (다) 정답 셔플 대조가 무너짐.

- 기준별로 통과를 기록하고, **1단계 도달 = 핵심 기준 모두 통과**.

### 뒤 판의 후보 — 자기 기준과 물건 기준이 어긋나는 상황 (사용자 결정 2026-10-17, 보이저 세션에서 — 정보)
