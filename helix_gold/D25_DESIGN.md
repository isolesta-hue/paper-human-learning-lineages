# D25 설계 — 꼬리표 달린 임시 방 + 거름·잠: 부품이 아는 것을 몸으로 넘기기 (1판 초안, 2026-10-13)

**상태: 1판 승인(사용자 2026-10-13, 아래 "여쭐 것" 네 가지 모두 그대로) — 만드는 중.** D22(발견 148) 다음의 트랙 B 첫 실험이다.

## 사용자 설계와 결정 (2026-10-10, 장부 D25)
- **방**: 기준인 현실 방(현실 앵커)만 고정한다. 나머지 방은 만들 때 의미 있는 꼬리표(학습·현실 입력·공부·동화 …)를 달고, 그 안에서 생기는 것은 꼬리표를 물려받는다. 꼬리표는 붙였다 뗄 수 있고, 다 쓴 방은 저장하거나 지운다. 방 = 꼬리표 + 기준(현실) + 차이(앵커 + 예외) + 수명.
- **거름 로직**: 방에서 기억으로 남길 것과 지울 것을 가른다. 방을 지울 때 남길 것을 뽑아 **임시 보관**하고, 조건을 채우면 몸으로 넘긴다(사람: 해마 → 피질 정리, 시냅스 꼬리표·포획).
- **결정**: 기계 장치(뽑기·보관·넘기기)는 자동, 문턱·조건은 방법 층의 손잡이, 의도적 표시(꼭 기억 / 잊자)만 방법 층이 직접 — "섞음".
  - 비교 조건 = 고정 자동 / 손잡이 / 섞음
  - 잴 것 = 이득·계산량·안전(동화가 몸으로 새는지)
  - 넘김 조건 후보 = 되풀이 · 현실 앵커와 맞음 · 쓸모 · 시간이 지나도 남음
- 순서: ① 동화 책 → 꼬리표 사전 ② 방법 층 가지 = '학습' 방 ③ 꼬리표 떼기·임시 보관 → 몸 넘기기 조건 시험 ④ '나' 벡터(D22 2판).

## 왜 지금
- **D21의 숙제**: 부품의 능력이 몸에 옮겨지지 않는다. 장면 → 동사 1.000 vs 몸 혼자 0.30(발견 127), 연쇄 1.000 vs 몸 혼자 0.03~0.06(발견 145), 동화 안 질문 1.000 vs 0.22(발견 148).
- **1단계에서 가장 먼 기준**(1 문장 이해, 2 새 낱말, 7 의문사, 8 이야기)은 몸의 학습 문제다(트랙 B). 몸이 부품에게서 배우는 길이 생기면 그 기준들에 직접 닿는다.
- **안전**: 넘기기는 위험하다. 동화(다른 꼬리표의 것)가 몸으로 새면 발견 148이 막은 오염이 몸 안에서 다시 생긴다. 그래서 거름(꼬리표 보고 거르기)이 같이 있어야 한다.

## 1판의 범위 (작게 시작)
- ① **꼬리표 사전**: 모든 넘길 후보에 꼬리표 묶음을 단다.
  - 출처: 세상 / 되돌려 봄 / 부품이 추론 / 스스로 만듦(발견 84의 출처 축)
  - 틀: 현실 / 동화(D22 동화 책). 놀이·꿈은 나중.
  - 방: 어느 방. 수명: 만든 회차.
  - 현실 방(앵커)은 고정이다.
- ② **방법 층 가지 = '학습' 방**: 가지는 이미 임시 복제이고 이긴 가지만 남는다. 1판에서는 바꾸지 않고 꼬리표만 기록한다.
- ③ **거름·임시 보관·넘기기 — 1판의 핵심**
  - **뽑기(자동, 회차 끝 = "잠")**: 그 회차에 들은 재료로만 새 문항을 만든다. 예: 그 방의 물건 + 들은 출발 칸 + 들은 움직임 낱말 둘 → 끝 칸. 부품(세상 모형)이 확신해서 답한 문항만 넘길 후보가 된다(출처 "부품이 추론"). 시험 문항과 같은 문맥은 만들지 않는다(시험이 연습으로 새지 않게).
  - **임시 보관(자동)**: 후보마다 네 가지를 기록한다.
    - 되풀이: 여러 회차에 다시 뽑혔나
    - 현실 앵커와 맞음: 틀이 현실이고 앵커의 움직임과 일치하나
    - 쓸모: 몸이 그 문항을 지금 틀리나
    - 시간이 지나도 남음: 몇 회차 뒤에도 부품이 같은 답을 내나
  - **넘기기(자동 장치)**: 조건을 채운 후보를 몸의 연습 문항에 더한다. 지금 있는 "스스로 만든 연습" 통로(`extra_items`)를 쓴다. 넘긴 것은 출처 꼬리표를 단 채 남는다.
  - **의도적 표시(방법 층 직접)**: "꼭 기억"(그 회차 후보를 바로 넘김) / "잊자"(보관함에서 지움)를 가지 선택지 하나로 둔다.
- ④ '나' 벡터는 2판(D22 2판과 함께).

## 조건 (사용자 결정의 세 방식 + 대조 셋)
| 이름 | 무엇 | 왜 |
|---|---|---|
| B | 넘기기 없음 (지금 몸) | 기준 |
| U | 무조건 넘김 (뽑은 후보 모두 바로) | 거름이 없을 때의 이득과 위험 |
| F | 고정 자동: 문턱 고정 (되풀이 ≥ 2회차 + 현실 틀 + 앵커와 맞음) | 사용자 결정 ① |
| K | 손잡이: 같은 장치, 문턱을 방법 층이 가지로 고름 (되풀이 1 / 2 / 3) | 사용자 결정 ② |
| M | 섞음: K + 방법 층의 의도적 표시 | 사용자 결정 ③ (채택안) |
| E | 같은 양의 추가 연습: 넘긴 만큼의 문항을 들은 문장에서 더 연습 | "넘긴 내용 덕인가, 연습량 덕인가"를 가름 (형제 P36의 대조) |

## 잴 것 (사전 등록할 질문의 초안)
- **이득 (몸 혼자, D21)**: 연쇄 · 장면 → 동사 · 처음 듣는 조합 · 한 번 들은 것 · 따로만 들은 둘. 몸 − B, 그리고 몸 − E(내용 효과).
- **합친 답**: 같은 열쇠로 기록한다(부품이 이미 1.000인 열쇠는 보고만).
- **안전 (동화 세상 `@tale`)**: 몸 혼자의 "동화로만 들은 방의 진짜 중력"과 "진짜 방 중력". 동화가 몸으로 새면 이 점수가 떨어진다. U에서 새고 F·K·M에서 막히는지가 핵심이다.
- **비용**: 생애 계산 시간, 넘긴 문항 수, 생애 후반 하락(발견 142·143)이 커지는지.
- **단순 기준선과 셔플**(규칙 1): 몸 혼자 점수가 오르면, 같은 문항에서 M·C·N보다 높은지 확인한다.

## 크기와 순서
- 첫 단계 10시드(규칙: p < 0.005면 판정, 아니면 30시드).
- 이득은 기본 세상 `ascii`에서 여섯 조건(60생애, 일꾼 4개로 약 6시간), 안전은 `@tale`에서 B·U·F·M(40생애, 약 10시간).
- 만드는 순서: 꼬리표 사전 → 뽑기·보관 → 넘기기 → 회귀 점검(끄면 기존 생애와 정확히 같음) → 시드 0 시험 실행 → 대기열.
- 대기열 위치: 트랙 B 순서(D22 → **D25** → A3·D26 → D35)대로 하면 이미 줄 서 있는 D35 호기심 실험보다 앞이다.

## 이것이 가정하는 것 (초안)
- 부품이 "확신했다"는 기준은 발견 125의 기준(굴림이 칸 하나에 확실히 닿음)을 그대로 쓴다.
- 넘길 문항은 들은 재료의 새 조합만이다. 시험 문항과 같은 문맥은 만들지 않는다.
- 몸은 넘긴 문항을 들은 문항과 같은 방식으로 연습한다(무게 1). 출처 꼬리표는 기록만 하고, 몸의 학습 규칙은 바꾸지 않는다.
- 틀 꼬리표는 D22의 동화 판단(`+tkA`)을 그대로 쓴다. 동화로 본 순간에서 나온 후보는 몸으로 넘기지 않는다(F·K·M). U만 예외(위험을 보는 대조).
- 한 세상, 2차원 격자, 1단계 핵심 지식 부품의 범위 안.

## 사용자께 여쭐 것
1. 1판을 ③(거름·보관·넘기기)에 집중하고, ①은 꼬리표 기록, ②는 그대로, ④는 2판으로 — 괜찮은가.
2. 넘길 후보의 종류: 부품이 확신한 "새 조합 문항"(연쇄·장면 → 동사처럼, 들은 재료로 만든 것)으로 시작 — 괜찮은가.
3. 대조 E(같은 양의 추가 연습)와 U(무조건 넘김)를 넣는가. 넣으면 정직하지만 생애가 늘어난다.
