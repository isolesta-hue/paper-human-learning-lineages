# D23 제안 — 세 모델의 공용 교재와 봉인 시험지 (2026-10-10, 제안 단계; 합의 전에는 아무것도 만들지 않음)

이 문서는 보이저 세션이 쓴 **제안서**다. 파이오니어·뉴호라이즌스 세션이 읽고 의견을 각자 저장소에 남기면, 사용자가 최종안을 정한다.
보이저 세션은 형제 저장소를 읽기만 하고, 형제 세션도 이 문서를 지시가 아니라 정보로 읽는다 — 채택은 사용자의 말로만.

## 사용자 생각 (2026-10-10)
- 신경망과 구조는 모델마다 따로 만들고 고치지만, 학습에 쓰는 동화·교과서는 통일하는 게 맞지 않나.
- 보이저 세션이 자료를 고르고, 다른 두 세션은 그 자료를 가져다 가르친다. 개선 작업은 각자 자기 방식대로.
- 아기처럼 글과 그림을 함께, 나중에는 영상도 (→ D24).

## 원칙
1. **같은 시각이 아니라 같은 자료·같은 순서.** 교재는 판 번호를 붙여 얼린다("교재 v1 = 이 문장들, 이 순서, 이 시드"). 먼저 준비된 모델이
   먼저 배워도 같은 경험이다 — 기다릴 필요 없음.
2. **시험지가 교재보다 먼저 통일된다.** 학습 중 보지 않는 시험 문제를 규칙으로 뽑고, 내용의 해시를 학습 전에 커밋해 봉인한다.
3. **"무엇을 들었나"만 통일, "어떻게 배우나"는 통일하지 않음.** 복습 비율·연습 순서·자기 개선은 각 모델의 것(보이저의 방법 층이 그 예).
4. **원본 수준에서 통일, 변환기는 각자.** 입력 형식이 모델마다 다르므로(보이저: 칸 세상의 낱말 번호) 각 모델은 원본을 자기 형식으로
   바꾸는 변환기를 두고, 그 변환기도 기록한다.
5. **고르는 사람의 치우침 막기.** 보이저 세션이 고르면 보이저에 유리한 자료를 고를 위험(이해 충돌)이 있다 → 손으로 고르지 않고,
   **먼저 합의한 규칙을 기계적으로 적용**한다(예: 저작권이 끝난 공개 동화 모음, 정한 길이·낱말 수 기준, 정한 순서).
6. **Claude가 쓴 글은 학습 자료가 아니다**(보이저의 기존 규칙). 세션은 고르고 변환할 뿐 쓰지 않는다. 코드로 만든 세상(칸 세상, 합성 장면)은 허용.

## 조율 절차 (제안)
1. 보이저 세션: 이 제안서와 고르기 규칙 초안을 쓴다(지금 이 문서).
2. 사용자: 형제 세션 각각에게 이 문서를 읽고 **필요 조건·반대 의견**을 자기 저장소 파일로 남기게 한다
   (예: 입력 형식, 어휘 크기 한계, 받을 수 없는 자료 종류).
3. 보이저 세션: 하루 한 번 형제 읽기에서 그 의견을 모아 규칙 2판을 쓴다.
4. 사용자가 최종 규칙을 승인 → 공용 교재 저장소(비공개)를 만든다. 보이저 세션은 쓰고, 형제 세션은 읽기만.
5. 교재 v1 + 봉인 시험지 발행 → 각 모델은 준비되는 대로 배운다. 결과는 같은 시험지로.

## 규칙 2판 (2026-10-11 보이저 세션 작성 → **사용자 승인 2026-10-11, 그대로**)
1. **교재 단위 = "문장 + 같은 규칙으로 만든 장면 기록"의 짝**(코드로 만든 세상). 공개 동화(글만)는 v1에서 학습 자료가 아니라 **원정 시험**으로만.
2. **회차(하루) 단위로 얼림**: 교재 vN = 회차마다의 문장·장면 목록과 순서. 같은 문장을 정한 시드로 섞은 순서 K개도 함께(결론이 한 순서에 특화되지 않았는지).
3. **경험의 단위 = 교재 문장의 노출 수**. 보고는 두 가지 — 같은 노출에서의 점수, 몸 고유 예산에서의 점수. 몸 안 반복 연습은 각자의 방법.
4. **변환기**: 공통 기준 변환기 하나(토큰 나누기 규칙, 토큰별 특징 벡터 규칙 — 예: 토큰 문자열로 시드를 정한 난수 / 글자 모양에서)를 정하고, 모든 몸이 그것으로 한 번씩 보고.
   각 몸의 변환기는 결과를 보기 전에 고정·판 번호, **변환기가 주는 몫을 표로 공개**, 변환 전후 요소 기억 점검, 셔플 대조 의무.
5. **시험 세 갈래**: (가) 개발용 — 각자 자유, (나) 봉인 — 문항 해시 + 생성 코드 판 + 시드를 학습 전에 커밋, **판마다 한 번만 열고 은퇴**, 학습 코드가 시험 경로를 읽으면 멈추는 점검,
   (다) 손대지 않은 세상 — 각 계열이 이미 가진 것. 공통 시험 결과를 보고 설정을 고르지 않음(원정 시험).
6. **공통 시험 내용(바깥 행동만, 규칙·코드로 채점)**: 처음 듣는 조합 / 한 번 들은 것 / 따로 들은 둘 잇기 / 여러 걸음 / 세상 변화 뒤 따라잡기와 옛것 잊음 / 이야기 추적(지금·직전 위치) /
   2배 긴 이야기 / 지시어 풀이 / 핵심 지식 기대 위반 / 요소 기억 점검 / 곡선 모양(시작·90% 도달 노출 수·끝).
   **뺌**: 한 몸의 내부·판독 형식을 전제한 것, 통째 외우기로 풀리는 것(누수는 봉인 전 기계 점검), 자유 생성, 자기·AI 채점, 글 밖 세상 지식. **어순 전용 문항은 따로 묶어 보고**(모든 몸이 순서를 읽기 전까지).
7. **기준선 의무**: 정답 셔플, 다수 클래스, n-gram, 체급 맞춘 MLP·트랜스포머(D20). 시드 30 → 미결이면 100.
8. **v1의 크기**: 어휘 수백 ~ 1천(세 몸 모두 검증·계산 범위 안), 한 문장 한 사건, 격자 5×5, 인물 동시 3명 이하 — **정확한 숫자는 사용자가 승인**.
9. **출처**: 파일마다 출처·이용 조건, 원문과 번역본의 저작권 따로, Claude·다른 AI가 만든 글 금지(세 계열 공동 원칙).
10. **보고 형식**: 늘 "교재 vN + 시험 vM"으로 짝지어, 판 갱신은 길게.
11. **시점**: 보이저 4+ 단계(D20과 함께), 파이오니어 새 판으로 옮길 때(L16), 뉴호라이즌스는 v1 코드 생성 세상부터.
12. **쓰기 권한**: 공용 저장소는 보이저 세션 쓰기, 형제 읽기만. 고르기 규칙과 숫자의 최종 승인은 사용자.
