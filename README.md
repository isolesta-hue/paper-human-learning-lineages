## In one paragraph
Infants first keep what they hear and see, then try to produce it from memory and correct themselves until it matches: the input is its own answer. Helix Gold is a small learner built around this internal imitation — memory first, connections without outside feedback, and a closed loop that tunes *how* it learns and keeps a change only when its own test says it is better. We gave it logic borrowed from infant learning (a world model read off its own first-hand moments on a grid centred on the self, per-object state, re-reading before speaking) and measured each piece by switching it off, pre-registered, over 30–100 seeds. The closed loop meets its pre-registered completion criterion, but the effect is small next to the designed logic, and rules outside the design are not learned. On a shared sealed exam taken by three independently built learners, Helix Gold's general body passed 0 of 10 criteria; a diagnosis rules out the most obvious cause and points to how names are asked. The paper reports this as an honest case of non-transfer.

## The three learners
| Public name | Body | Working name (in code, records and review files) |
|---|---|---|
| **Helix Gold** | GRA — memory parts split by role, plus a self-tuning method layer | Voyager (its session: "Dami") |
| **Helix Teal** | a small transformer | Pioneer ("Ara") |
| **Helix Blue** | BatonNet — a brain-principle grid with hippocampus-like memory | New Horizons ("Sia") |

The paper uses the public names. Code comments and research records keep the working names, because the records cite them.

## Reproducing
Environment used: Python 3.11, PyTorch 2.14.0, NumPy 2.4.6, CPU only. Answers and results are identical to the last digit only with every BLAS library on one thread:
```
export OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1
```
- **Regenerate edition v1 and check it**: `python3 -m exam.edition --phrase "아는 것이 힘이다." --lives 30 --out /tmp/v1_check` — every file hash in the new `manifest.json` equals `exam/v1/manifest.json`.
- **Grade**: unpack the answer files (`gunzip -k answers/v1/*/*.jsonl.gz answers/v1/helix_teal/*/*.jsonl.gz`), then `python3 -m exam.grade --edition exam/v1 --report-only exam_spec/report_only.json --answers helix_gold=answers/v1/helix_gold helix_blue=answers/v1/helix_blue helix_teal_whole=answers/v1/helix_teal/whole helix_teal_alone=answers/v1/helix_teal/alone`.
- **Baselines**: `python3 -m exam.baselines --edition exam/v1 --out DIR` (six simple) and `python3 -m exam.learned --edition exam/v1 --out DIR` (four learned; about a day on four CPUs). Their answer files are not included; they are regenerated by these commands.
- **Helix Gold's results**: each finding in `helix_gold/README.md` names its runner (`run_*.py`, usually `python3 run_xxx.py <seeds> [workers]`) and its output file (`*.out`). Run from `helix_gold/`.
