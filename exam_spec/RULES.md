## 규칙 2판 (2026-10-11 보이저 세션 작성 → **사용자 승인 2026-10-11, 그대로**)
1. **교재 단위 = "문장 + 같은 규칙으로 만든 장면 기록"의 짝**(코드로 만든 세상). 공개 동화(글만)는 v1에서 학습 자료가 아니라 **원정 시험**으로만.
2. **회차(하루) 단위로 얼림**: 교재 vN = 회차마다의 문장·장면 목록과 순서. 같은 문장을 정한 시드로 섞은 순서 K개도 함께(결론이 한 순서에 특화되지 않았는지).
3. **경험의 단위 = 교재 문장의 노출 수**. 보고는 두 가지 — 같은 노출에서의 점수, 몸 고유 예산에서의 점수. 몸 안 반복 연습은 각자의 방법.
4. **변환기**: 공통 기준 변환기 하나(토큰 나누기 규칙, 토큰별 특징 벡터 규칙 — 예: 토큰 문자열로 시드를 정한 난수 / 글자 모양에서)를 정하고, 모든 몸이 그것으로 한 번씩 보고.
   각 몸의 변환기는 결과를 보기 전에 고정·판 번호, **변환기가 주는 몫을 표로 공개**, 변환 전후 요소 기억 점검, 셔플 대조 의무.
5. **시험 세 갈래**: (가) 개발용 — 각자 자유, (나) 봉인 — 문항 해시 + 생성 코드 판 + 시드를 학습 전에 커밋, **판마다 한 번만 열고 은퇴**, 학습 코드가 시험 경로를 읽으면 멈추는 점검,
   (다) 손대지 않은 세상 — 각 계열이 이미 가진 것. 공통 시험 결과를 보고 설정을 고르지 않음(원정 시험).
   **5번 고침(사용자 승인 2026-10-12)**: (나)의 봉인은 "문항 해시 + 시드를 학습 전에 커밋" 대신, 생성 코드 판·채점 코드·통과선·기준선 실행기·각 몸의 변환기 판을 여는 날 전에 해시로 고정하고,
   **문항은 여는 날 사용자가 정해 주는 말(씨앗)로 생성**한 뒤 바로 문항 해시를 커밋한다. 판은 세 모델이 같은 날 함께 열고, 판을 거듭한다(v1, v2, …). 완성은 다음 판에서 한 번 더 통과해야 적고,
   판 사이는 최소 2주, 기준선은 판마다 같은 문항으로 돌린다. 자세한 것은 `STAGE1.md` 끝 절.
6. **공통 시험 내용(바깥 행동만, 규칙·코드로 채점)**: 처음 듣는 조합 / 한 번 들은 것 / 따로 들은 둘 잇기 / 여러 걸음 / 세상 변화 뒤 따라잡기와 옛것 잊음 / 이야기 추적(지금·직전 위치) /
   2배 긴 이야기 / 지시어 풀이 / 핵심 지식 기대 위반 / 요소 기억 점검 / 곡선 모양(시작·90% 도달 노출 수·끝).
   **뺌**: 한 몸의 내부·판독 형식을 전제한 것, 통째 외우기로 풀리는 것(누수는 봉인 전 기계 점검), 자유 생성, 자기·AI 채점, 글 밖 세상 지식. **어순 전용 문항은 따로 묶어 보고**(모든 몸이 순서를 읽기 전까지).
7. **기준선 의무**: 정답 셔플, 다수 클래스, n-gram, 체급 맞춘 MLP·트랜스포머(D20). 시드 30 → 미결이면 100.
8. **v1의 크기**: 어휘 수백 ~ 1천(세 몸 모두 검증·계산 범위 안), 한 문장 한 사건, 격자 5×5, 인물 동시 3명 이하 — **정확한 숫자는 사용자가 승인**.
9. **출처**: 파일마다 출처·이용 조건, 원문과 번역본의 저작권 따로, Claude·다른 AI가 만든 글 금지(세 계열 공동 원칙).
10. **보고 형식**: 늘 "교재 vN + 시험 vM"으로 짝지어, 판 갱신은 길게.
